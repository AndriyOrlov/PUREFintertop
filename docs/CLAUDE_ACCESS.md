# Claude access to this private repository

Status: not granted by this project. A code connector cannot change another
GitHub App's installation permissions. Do not invite an arbitrary account named
Claude as a collaborator.

For the Claude GitHub integration, the owner opens
https://github.com/settings/installations, configures the Claude installation,
selects `AndriyOrlov/PUREFintertop` in repository access and saves. If Claude is
not installed yet, connect GitHub from Claude first. Then sync this repository
in Claude and review using `CLAUDE.md`.

Official instructions:
https://support.claude.com/en/articles/10167454-use-the-github-integration

App permissions and installation availability must be checked in the owner's
account; repository privacy remains enabled.
